## 🔭 What I'm working on

### Forensiq

An AI-powered security operations and investigation platform I'm building with my team.

The idea is simple: **make security alert investigation less manual** by using AI agents to help with things like IOC analysis, threat intelligence, MITRE ATT&CK mapping and incident investigation.

It's currently a work in progress, and I'm learning a lot while building it.

**Stack:** `Python` `FastAPI` `Next.js` `TypeScript` `PostgreSQL` `LangGraph` `Docker`
